Skill, script or MCP? Each does its part

  • APIs fetch facts. Apollo's MCP server is wired in for people search, which this Apollo plan refused.
  • Code decides order, readiness, contacts and what may be shown: a rule in a prompt is a request, in code it is a guarantee.

Scope

What I assumed, and what I left out

Assumptions

  • Each system's own permissions are the right scope, so everything runs as the rep.
  • RevOps owns the ICP, in a file anyone can read and change without code.
  • Calls and tickets live in Salesforce: Gong as a mirrored object, Cases as the support desk.
  • A rep forgives a gap they can see: a source that fails says "Not checked."

Left out on purpose

  • Sending email or drafts
  • Any write without approval
  • A stored copy of CRM data
  • A model score for ranking
  • Mobile numbers
  • A hosted server: Socket Mode needs none
